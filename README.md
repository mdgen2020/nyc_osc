# mikedai_OSC_UnclaimedFunds

**Demonstration Only. Not an official New York State Office of the State Comptroller (OSC) project.** Fictional data only. Do not enter real personal information. The real OSC site is <https://ouf.osc.ny.gov/>. Nothing here calls, scrapes or imitates OSC production systems, and no OSC code, assets or logo are used.

A complete demo for the Office of Unclaimed Funds covering the seven claim stages (find property and submit a claim, receive or recover a Claim ID, learn what else is needed, check status, submit documents, wait for review, approval and payment), with **high-volume claim-status automation** as the primary use case.

```
Voice or GitHub Pages website -> Architect flow -> AVA -> Genesys Data Actions -> Supabase -> resolution or support_miked
AVA -> Knowledge Setting -> Miked_SharePT -> SharePoint -> mikedai_OSC_GeneralKnowledge.md
```

## Run locally

Prereqs: Node 22+, Deno 2+.

```bash
# backend + contract + RLS tests (47)
deno test --allow-read --allow-env --allow-net tests/backend

# website (local-demo mode needs no backend and no secrets)
cd web && npm ci && npm test && npm run dev
VITE_BASE=/mikedai_OSC_UnclaimedFunds_Demo/ npm run build   # production build as GitHub Pages serves it
```

Local-demo credentials for the fictional personas are in [`docs/demo-script.md`](docs/demo-script.md). The simulated code appears in the on-page demo inbox; no real SMS or email is sent.
